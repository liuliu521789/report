中来标签 - 用宏刷新二维码（手动安装，约 1 分钟）
================================================

可以。宏能解决「改表后二维码不更新」：改右侧表 → 点「刷新二维码」→ 按 G 列重绘图片。

------------------------------------------------
一、准备
------------------------------------------------
1. 打开你的标签文件（建议用：中来标签 - PR02-fixed-qr.xlsx）
2. 另存为：Excel 启用宏的工作簿（*.xlsm）
3. 宏模块文件在：
   d:\report\scripts\ZhonglaiQR.bas

------------------------------------------------
二、导入宏
------------------------------------------------
1. 按 Alt + F11 打开 VBA 编辑器
2. 菜单：文件 → 导入文件
3. 选中 ZhonglaiQR.bas → 打开
4. 关闭 VBA 窗口
5. 保存 xlsm

若提示无法导入：文件 → 选项 → 信任中心 → 宏设置
→ 勾选「信任对 VBA 项目对象模型的访问」（仅安装时需要）

------------------------------------------------
三、加按钮（可选）
------------------------------------------------
1. 开发工具 → 插入 → 按钮（窗体控件）
   （没有「开发工具」：文件 → 选项 → 自定义功能区 → 勾选开发工具）
2. 在「批次序列」表上方画一个按钮
3. 指定宏：RefreshZhonglaiQRCodes
4. 按钮文字改成：刷新二维码

或直接 Alt + F8 → 选 RefreshZhonglaiQRCodes → 运行

------------------------------------------------
四、日常使用
------------------------------------------------
1. 只改右侧 I~S 列（品号/批号/数量/日期等）
2. 不要手改 G 列（公式会自动拼二维码内容）
3. 点「刷新二维码」
4. 需能访问外网（宏用 api.qrserver.com 生成图片）

若公司网络拦外网：改用桌面「刷新中来标签二维码.bat」（离线 Python，不依赖宏）

------------------------------------------------
说明
------------------------------------------------
原文件里的二维码是静态图片，Excel/WPS 不会自动跟着单元格变。
宏做的事：读 G 列 → 生成新二维码图 → 替换左侧图片。
